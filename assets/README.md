# Brand artwork

The app logo was generated with the built-in imagegen tool, then mechanically resized into macOS icon representations. It is included under the repository’s MIT license.

- Source PNG: [`Sources/FocusIsland/Resources/AppIcon.png`](../Sources/FocusIsland/Resources/AppIcon.png)
- Native macOS icon: [`AppIcon.icns`](AppIcon.icns)
- Rebuild icon sizes: `./scripts/build-icon.sh`
- `CFBundleIconFile=AppIcon` in the packaged app enables the Finder, Spotlight, and application icon.

## Generation prompt

Use case: logo-brand. Asset type: final 1024x1024 macOS application icon for Focus Island, a native focus tracking app for programmers. Create one beautifully finished, distinctive, minimal icon, no text. A premium charcoal-black macOS rounded-square squircle tile, facing perfectly straight-on, filling about 88% of the square image with balanced transparent outer margins. Inside: a single large sculpted mint-green continuous loop suggesting a small floating island and a calm focus pulse, an abstract low rounded capsule orbit with three ascending rounded vertical waveform pillars in its center. Extremely simple silhouette readable at 16px; pillars and orbit form one coherent original symbol. Subtle dimensional bevel, soft mint highlights, restrained shading, dark tile gently satin, contemporary macOS craftsmanship. Palette follows app: almost black #101316 and soft mint #A3F0B0. Centered and optically balanced. Transparent outside the rounded-square tile. No lettering, no labels, no Apple logo, no code brackets, no mockup, no multiple variants, no presentation board, no cast shadow outside the icon tile.
